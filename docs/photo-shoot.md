# Kairo photo shoot

32 products × 2 photos. Generated from the catalog by `npm run photos:prompts`; don't edit by hand.

## How it works

1. Paste a prompt into your image tool (ChatGPT, Gemini, Midjourney, Leonardo… any of them).
2. Save the result in the folder named under each product, as `1.jpg` (worn) or `2.jpg` (close-up). Any of jpg, png, webp or avif. At least 600×800; bigger is better.
3. When a few are in, run `npm run photos -- --check` to test the folder, then `npm run photos` to upload.
4. Set `NEXT_PUBLIC_PRODUCT_PHOTOS=1` in `.env.local` and restart `npm run dev`.

```
kairo/
  photos/                  ← next to package.json (never uploaded to GitHub)
    static-heavy-tee/
      1.jpg                ← worn
      2.jpg                ← close-up (optional)
    boardroom-blazer/
      1.png
```

You don't need all of them at once. Pieces without a photo keep their drawing; the worn photo (1) matters most.

## Before you keep a picture, check

- **One man only.** No women anywhere in the frame, including in the background. Regenerate if there are.
- The garment matches: right colour, right kind of piece, sensible details.
- Hands, fingers and faces look natural.
- No text, logos, brand names or watermarks.
- The same collection looks like one shoot: same model, set and light. Generating a whole collection in one chat helps the tool stay consistent.

These are AI concept visuals; the site says so in the footer and on the About page.
